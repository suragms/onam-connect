# Code of Conduct

## Our pledge

We are committed to a welcoming, respectful community for everyone contributing to ONAMCONNECT.

## Our standards

**Positive behavior includes:**

- Being respectful and constructive
- Welcoming newcomers
- Focusing on what is best for the community and the project

**Unacceptable behavior includes:**

- Harassment, discrimination, or personal attacks
- Trolling, insults, or derogatory comments
- Publishing others’ private information without permission
- Sharing or soliciting secrets, API keys, or credentials

## Enforcement

Project maintainers may remove or reject contributions that violate this code of conduct, and may temporarily or permanently ban contributors for harmful behavior.

## Scope

This Code of Conduct applies within project spaces (issues, PRs, discussions) and when representing the project publicly.

## Reporting

Report concerns to the repository maintainers via a private channel (for example a private GitHub security advisory or maintainer contact listed on the GitHub profile). Do not post sensitive details in public issues.
